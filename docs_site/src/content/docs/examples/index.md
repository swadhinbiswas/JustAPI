## Full Application

The [demo_shop](https://github.com/swadhinbiswas/JustAPI/tree/main/demo_shop) is a complete e-commerce application with 23 endpoints:

- Catalog (categories, products, sellers)
- Customers (register, lookup)
- Cart (add, remove, checkout)
- Orders (create, list, status lifecycle)
- Reviews (CRUD, analytics)

All examples are in the [`examples/`](https://github.com/swadhinbiswas/JustAPI/tree/main/examples) directory of the repository.
