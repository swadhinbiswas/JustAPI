## Quick Start

```python
from justapi import JustAPIApp

app = JustAPIApp()

@app.get("/")
def hello():
    return {"message": "Hello from JustAPI!"}
```

```bash
pip install justapi
python main.py
# → http://127.0.0.1:8000/docs
```

## Install

```bash
pip install justapi           # pip
uv pip install justapi        # uv (recommended)
uvx justapi create my_app     # scaffold without installing
```

## Migration

```python
# FastAPI                          # JustAPI
from fastapi import FastAPI    →   from justapi import JustAPIApp
app = FastAPI()                →   app = JustAPIApp()
```

Everything else — decorators, Pydantic, DI, OpenAPI — stays the same.
