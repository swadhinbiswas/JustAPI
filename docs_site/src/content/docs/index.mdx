## Features

<div class="ja-grid">
  <div class="ja-card">
    <div class="ja-card-icon">⚡</div>
    <h3>Rust core</h3>
    <p>Networking, TLS, routing, serialization run in Rust. Python executes only your logic.</p>
  </div>
  <div class="ja-card">
    <div class="ja-card-icon">🗄️</div>
    <h3>Native async DB</h3>
    <p><code>await app.db.query_async()</code> runs SQL on Rust's tokio runtime — 53× faster on slow queries.</p>
  </div>
  <div class="ja-card">
    <div class="ja-card-icon">📡</div>
    <h3>Rust-native SSE</h3>
    <p><code>app.sse_native()</code> streams events with zero Python per event.</p>
  </div>
  <div class="ja-card">
    <div class="ja-card-icon">🚀</div>
    <h3>Multi-worker</h3>
    <p><code>justapi serve --workers N</code> — 1.88× throughput at 4 workers, auto-scale.</p>
  </div>
  <div class="ja-card">
    <div class="ja-card-icon">🧠</div>
    <h3>Free-threaded</h3>
    <p>CPython 3.14t wheels — CPU-bound Python scales with cores, 12.4× measured.</p>
  </div>
  <div class="ja-card">
    <div class="ja-card-icon">🔐</div>
    <h3>Security built-in</h3>
    <p>JWT, rate limiting, CORS, security headers — all in Rust middleware.</p>
  </div>
  <div class="ja-card">
    <div class="ja-card-icon">🛡️</div>
    <h3>Production-ready</h3>
    <p>Circuit breakers, OTel tracing, Prometheus metrics, health checks.</p>
  </div>
  <div class="ja-card">
    <div class="ja-card-icon">📋</div>
    <h3>Type-checked</h3>
    <p><code>py.typed</code> + complete stubs — mypy-clean on user code.</p>
  </div>
  <div class="ja-card">
    <div class="ja-card-icon">🔗</div>
    <h3>FastAPI-compatible</h3>
    <p>Same decorators, Pydantic models, Depends. Migrate with one import.</p>
  </div>
</div>

## Framework comparison

| | FastAPI | JustAPI |
|---|---|---|
| **Server** | uvicorn (Python) | Rust (tokio + hyper) |
| **Hello-world** | ~36k req/s | **~766k req/s** |
| **JSON echo** | ~33k req/s | **~782k req/s** |
| **Native DB SELECT** | Python driver | **181k req/s (×125)** |
| **Memory** | 29 MB | **12 MB** |
