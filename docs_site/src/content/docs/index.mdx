## Why JustAPI?

JustAPI moves the entire networking stack out of Python. Same FastAPI syntax. Same Pydantic models. 20× the throughput.

<CardGrid stack>
  <Card title="700,000+ Requests / Sec" icon="rocket">
    Networking, TLS, routing, schema validation, and JSON serialization run entirely in Rust at native speed. 20× faster than FastAPI + Uvicorn.
  </Card>
  <Card title="FastAPI Compatibility" icon="star">
    Same `@app.get()` decorators, same Pydantic v2 schemas, same `Depends()` dependency injection. Migrate existing FastAPI applications with one import change.
  </Card>
  <Card title="Zero-GIL Fast Path" icon="shield">
    Rust releases the Python GIL during all I/O, routing, and validation. Fully supports Python 3.13t/3.14t free-threading. Native fast path at 724k+ RPS.
  </Card>
  <Card title="Multi-Database & Multi-Protocol" icon="setting">
    SQL (Postgres, MySQL, SQLite), OLAP (DuckDB), NoSQL (Redis, MongoDB), and REST, GraphQL, gRPC, JSON-RPC 2.0 — all in one framework.
  </Card>
</CardGrid>

## Performance

| Framework | Requests/sec | p50 Latency | p99 Latency |
|---|--:|--:|--:|
| **JustAPI (native fast path)** | **701,234** | **0.07 ms** | **0.19 ms** |
| **JustAPI (Python handler)** | **60,297** | **1.03 ms** | **5.21 ms** |
| Robyn 0.88 | 39,103 | 1.78 ms | 11.47 ms |
| Granian | 69,195 | 0.72 ms | 3.87 ms |
| FastAPI + Uvicorn | 36,189 | 1.72 ms | 24.63 ms |

All measurements on the same hardware (i5-13600K, 20 threads), 100 concurrent connections, 30s duration. See [Benchmarks](/reference/adr-index/) for methodology.

## Quick Start

```python
from justapi import JustAPIApp

app = JustAPIApp(title="My API")

@app.get("/")
def hello():
    return {"message": "Hello from JustAPI!"}

@app.get("/items/{item_id}")
def read_item(item_id: int, q: str | None = None):
    return {"item_id": item_id, "q": q}
```

```bash
pip install justapi
python main.py
```

Open [http://localhost:8000/docs](http://localhost:8000/docs) for interactive Swagger UI documentation.

## Install

```bash
# pip
pip install justapi

# uv (recommended)
uv pip install justapi

# run without installing
uvx justapi create my_app
```

## Migration

Migrating from FastAPI? One import change:

```python
# Before (FastAPI)
from fastapi import FastAPI
app = FastAPI()

# After (JustAPI)
from justapi import JustAPIApp
app = JustAPIApp()
```

Everything else stays the same — decorators, Pydantic models, dependency injection, OpenAPI docs.
