## Why JustAPI

<div class="feature-grid">
  <div class="feature-card">
    <h3>Rust Core</h3>
    Networking, TLS, routing, serialization — all in Rust before your code runs.
  </div>
  <div class="feature-card">
    <h3>Native Async DB</h3>
    `await app.db.query_async()` — SQL on Rust's tokio runtime, loop never blocked.
  </div>
  <div class="feature-card">
    <h3>Rust-Native SSE</h3>
    `app.sse_native()` streams events with zero Python per event.
  </div>
  <div class="feature-card">
    <h3>Multi-Worker</h3>
    `justapi serve --workers N --scale` — 1.88x throughput at 4 workers.
  </div>
  <div class="feature-card">
    <h3>Free-Threaded</h3>
    CPython 3.14t wheels — CPU-bound Python scales with cores.
  </div>
  <div class="feature-card">
    <h3>Type-Checked</h3>
    `py.typed` + complete stubs — mypy-clean on user code.
  </div>
</div>

## Framework vs FastAPI

| | FastAPI | JustAPI |
|---|---|---|
| **Server** | uvicorn (Python) | Rust (tokio + hyper) |
| **Hello-world** | ~36k req/s | **~766k req/s** |
| **JSON echo** | ~33k req/s | **~782k req/s** |
| **Native DB SELECT** | Python driver | **181k req/s (×125)** |
| **Memory** | 29 MB | **12 MB** |
| **OpenAPI docs** | /docs | /docs |
