## What It Does

JustAPI runs your Python application logic on top of a Rust networking stack. Routing, TLS, serialization, compression — all handled in Rust before your code even runs.

```python
from justapi import JustAPIApp

app = JustAPIApp()

@app.get("/")
def hello():
    return {"message": "Hello from JustAPI!"}
```

```bash
pip install justapi
python main.py
# → http://127.0.0.1:8000/docs
```

Open the `/docs` endpoint and you get Swagger UI, ReDoc, and the full OpenAPI schema — generated automatically from your code.

## Install

```bash
pip install justapi           # pip
uv pip install justapi        # uv (recommended)
uvx justapi create my_app     # scaffold without installing
```
