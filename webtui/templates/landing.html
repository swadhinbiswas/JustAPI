uv pip install justapi
uv run main.py
uvx justapi create my_app
cd my_app && python app/main.py
Minimal app
 main.py
from justapi import JustAPIApp

app = JustAPIApp()

@app.get("/")
def hello():
    return {"Hello": "World"}

app.run()

Features


Rust core

Networking, TLS, routing, serialization run in Rust. Python executes only your logic.



Native async DB

await app.db.query_async() runs SQL on Rust's tokio runtime — 53× faster on slow queries.



Rust-native SSE

app.sse_native() streams events with zero Python per event.



Multi-worker

justapi serve --workers N — 1.88× throughput at 4 workers, auto-scale.



Free-threaded

CPython 3.14t wheels — CPU-bound Python scales with cores, 12.4× measured.



Security built-in

JWT, rate limiting, CORS, security headers — all in Rust middleware.



Production-ready

Circuit breakers, OTel tracing, Prometheus metrics, health checks.



Type-checked

py.typed + complete stubs — mypy-clean on user code.



FastAPI-compatible

Same decorators, Pydantic models, Depends. Migrate with one import.
