# JustAPI Documentation Site — Production-Grade Build Plan

> **Goal:** Build a comprehensive, production-grade documentation site (Astro + Starlight) covering every aspect of the JustAPI runtime — matching the depth, polish, and discoverability of FastAPI, Next.js, and Django docs.
>
> **Current state (2026-07-24):** `docs_site/` exists with Astro + Starlight but has only 10 pages covering 20% of the framework surface. `docs/` has 7 raw markdown files capturing the handbook, API reference, security, and migration guide. The full codebase has **5 Rust crates**, **~40 public modules**, **33 benchmark scripts**, **12 examples**, **13 test files**, **8 fuzz targets**, **5 cloud deployment guides**, **Helm chart**, **Docker setup**, and **agent-native demo**.

## Key Design Principles

1. **Every page must answer:** What is it? Why does it matter? How do I use it? Where does it fit in the architecture?
2. **Code examples always runnable** — tested with the actual framework
3. **Performance numbers everywhere** — JustAPI's differentiator is speed; every feature page should show the benchmark
4. **Visual hierarchy** — architecture diagrams (Mermaid), screenshots, comparison tables
5. **Progressive disclosure** — tutorial → how-to → reference → deep-dive
6. **Search-first** — every concept should be findable via Pagefind within 2 clicks
7. **Mobile-friendly** — all diagrams, tables, and code blocks responsive
8. **Accessible** — WCAG 2.1 AA, semantic HTML, proper ARIA labels
